name: plan-change
description: Plan a change when the scope, affected specifications, risks, or validation need evidence before any code is written.
---

This skill will gather the evidence a change needs before code is written: the clauses
it touches, the invariants in `AGENTS.md` it bears on, its risks and how it will be
validated. It is carried from the Pawdoku skill of the same name, and ticket T05 writes
its full procedure. Until then, follow `AGENTS.md` and prove the work with `just check`
and then `just check`.
