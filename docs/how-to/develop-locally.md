# Develop locally

This page will list the prerequisites and the first run: rustup ahead of any other cargo
on the path, pixi, just and gh, what `just initialize` installs (the pixi environment,
the tools it cannot own) and what it downloads, and the caveats of a first run without a network. It is rewritten from the
Pawdoku page of the same path by lane T07.
