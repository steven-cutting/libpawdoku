# Develop locally

This page will list the prerequisites and the first run: rustup ahead of any other cargo
on the path, cargo-binstall, just, uv and gh, what `just initialize` installs and what
it downloads, and the caveats of a first run without a network. It is rewritten from the
Pawdoku page of the same path by lane T07.
