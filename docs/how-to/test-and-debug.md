# Test and debug

This page will show how to run a narrow slice of the tests with nextest filters, how
doctests run beside them, how to open the coverage report as HTML, and how to get a
backtrace from a failing test. It is a shorter adaptation of the Pawdoku page of the
same path, written by lane T07.
