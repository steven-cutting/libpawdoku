# Make your first change

This tutorial will take a newcomer once through every layer: clone the repository, run
`just initialize`, change one clause in a specification, derive a test from it, make the
engine pass it, and finish on a green `just check`. It is rewritten from the Pawdoku
tutorial of the same path by lane T07.
