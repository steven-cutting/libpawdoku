# Maintenance

This page will describe the routine upkeep of the repository: rotating the tool pins,
moving the Allium binary and its checksums, and confirming that the repository holds no
secrets to rotate. It is a shorter adaptation of the Pawdoku page of the same path,
written by lane T08.
