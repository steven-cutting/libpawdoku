# Troubleshooting

This page will collect the failures a contributor is likely to meet and their fixes: a
pixi or Homebrew cargo shadowing rustup, a missing Allium binary, the first lint run
needing the network, and a locked build refusing a stale lockfile. It is rewritten from
the Pawdoku page of the same path by lane T08.
