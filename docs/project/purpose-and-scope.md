# Purpose and scope

This page will say what the engine is for and what it deliberately is not. It is a
library that solves, rates and explains classic sudoku; it has no user interface, no
persistence and no puzzle generation yet, and the game Pawdoku, a command line and
Python bindings are its consumers. It is rewritten from the Pawdoku page of the same
path by lane T07.
