# Terminology

This page will define the words this repository uses precisely. It keeps the entry for
the repository itself, and takes the engine's vocabulary (grid, cell, candidate, given,
technique, step budget) from the specifications, starting with the rules of sudoku and
the board in play (board, move, undo, redo, check, record). It is a shorter adaptation
of the Pawdoku page of the same path, written by lane T07.
