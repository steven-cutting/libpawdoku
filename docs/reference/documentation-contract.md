# Documentation contract

This page will state the rules every handbook page obeys: registration in the manifest,
frontmatter equal to its entry, one owner per topic, reachability from the map, a
minimum length and exact-case links. It is carried from the Pawdoku page of the same
path without the managed and seed paragraph, by lane T08.
