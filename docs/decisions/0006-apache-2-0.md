# Decision 0006: Apache-2.0

## Context

This is the first licensed repository in the house; the earlier ones carry no licence.
This one will be read and built by strangers: a library the game consumes as a package,
a command line, and Python and WebAssembly packages whose registries each ask for a
licence field. The crates are `publish = false` until the release process is decided, but
a licence is decided at the first commit, because every later contribution is made under
it and relicensing afterwards means asking every contributor.

## Decision

Apache-2.0. `LICENSE` at the repository root is the licence's verbatim text;
`license = "Apache-2.0"` sits in `[workspace.package]` and every crate inherits it. No
dual MIT/Apache, no per-file headers, no `NOTICE` file.

Apache over MIT for two clauses MIT lacks. Section 3 grants every user a patent licence
from every contributor and terminates it for anyone who sues over the work, and section 5
places every contribution under the licence's terms automatically, which does the work a
contributor agreement would otherwise do. Not the Rust ecosystem's dual MIT/Apache: that
pairing exists so that MIT-only and GPLv2 consumers can take a crate, the consumers here
are house games, and one licence is one thing to explain. No per-file headers: the
licence's appendix makes them optional, and a header is one more thing every new file
gets wrong. No `NOTICE`: section 4(d) obliges a redistributor to carry a `NOTICE` only
where one exists, and nothing here needs attribution beyond the licence itself.

## Consequences

Apache-2.0 is incompatible with GPLv2-only programs, which cannot link it. Accepted: no
consumer in sight is one.

Every dependency must be compatible. `deny.toml` carries an allow list of licences,
Apache-2.0, MIT, the BSD family, ISC, Zlib, 0BSD, Unicode-3.0, Unlicense and CC0-1.0, and
`cargo deny check licenses` at gate 12 of `just check` fails on any crate outside it, so
a copyleft dependency cannot arrive by accident.

A contributor's work is licensed by section 5 with no separate agreement; the repository
asks for nothing beyond the pull request.

## What would reopen this

A consumer that can only take MIT. Adding it is additive and needs no relicensing of past
contributions, because section 5 already licenses them under terms that permit it, so the
change would be a second licence file, a `license = "MIT OR Apache-2.0"` line and a
record superseding this one. Or the house choosing one licence for every repository, at
which point this record follows that decision.
