# Security policy

## Supported versions

Only the `main` branch is supported. No version of the library has been released or
published yet, so there is no older line that receives fixes.

## Reporting a vulnerability

The reporting route is decided together with the repository's visibility when the
GitHub repository is created, in ticket T01: private vulnerability reporting needs a
public repository, and a private one needs another channel. Until then, report a
suspected vulnerability to the maintainer directly rather than in a public issue. Ticket
T10 writes the rest of this policy, and the
[security model](docs/explanation/security-model.md) says what the library defends.
